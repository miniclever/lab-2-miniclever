# Лабораторная работа №2: Инфраструктура и пайплайны AI-агентов

**Дисциплина:** Технологии и методы программирования
**Организация:** omsu-mbs-401

## 📌 Бизнес-задача

Данный репозиторий является шаблоном для сдачи второй лабораторной работы. 
В рамках этой работы вы создаете production-ready инфраструктуру для AI-агента (OpenClaw) на выделенном VPS-сервере, интегрируете локальные инструменты с помощью протокола MCP (Model Context Protocol) и проектируете enterprise-архитектуру финансово обоснованного мониторинга.

Лабораторная работа состоит из двух частей:
1. **Инфраструктура:** Развертывание базового Telegram-бота с AI на Node.js.
2. **AI Engineering (MCP + Observability):** Подключение инструментов и проектирование матрицы надежности.

---

## 🛠️ Часть 1: Интеграция Model Context Protocol (MCP)

Вы должны настроить 3 инструмента (Tools) для вашего агента, чтобы он перестал быть просто чат-ботом и получил доступ к внешнему миру.

**Требования к интеграциям:**
1. **Сетевой доступ (RSS/Fetch):** Агент должен уметь читать новости с внешних сайтов. Решите проблему "Indirect Prompt Injection".
2. **Доступ к файловой системе (FS):** Агент должен уметь читать локальные файлы на сервере. Решите проблему *Scope Sandboxing* с помощью файла `.mcpignore`.
3. **Аналитик Баз Данных (NL2SQL):** Поднимите тестовую SQLite-базу и научите агента делать SQL-выборки (Schema Discovery).

**Сдача Части 1:** В директорию `logs/` этого репозитория загрузите сырые `JSON-RPC` логи обмена вашего агента с MCP-серверами (например, `mcp_fs.log`). Скриншоты терминала не принимаются.

## 📐 Часть 2: Проектирование Observability-матрицы

Инженер обязан понимать стоимость своей облачной архитектуры. 

В папке `architecture/` откройте файл `architecture.md` и сделайте следующее:
1. **Отрисуйте схему (Architecture as Code).** Используйте синтаксис Mermaid.js. Покажите три уровня зрелости (Hobbyist -> Startup -> Enterprise). Явно обозначьте зоны (Локальная сеть, VPS, Cloud API).
   > **Важно:** Ваша Enterprise-схема обязана включать компоненты AI Gateway (LiteLLM/RouteLLM), кэширование (Redis), Fallback-маршрутизацию, логирование LLM-трейсов (Langfuse/LangSmith) и системный мониторинг (Prometheus/Grafana/Loki).
2. **Проведите FinOps-анализ.** Соберите Enterprise-кластер на официальном калькуляторе (Yandex Cloud/Selectel) и сравните его стоимость с инфраструктурой базового сегмента (Budget VPS). Обоснуйте выбор бизнесу: за что именно корпорации платят кратно больше (SLA, управляемые сервисы, гео-резервирование)?
